================================================================================
                       HOW TO USE REPORTS
================================================================================

AS AN ADMIN:
  1. Login as admin
  2. Click "Reports" button in top navigation
  3. On Reports Center, select a report type
  4. Click "Generate Report"
  5. View summary statistics and data table
  6. Click export button:
     - PDF: Downloads formatted PDF file
     - CSV: Downloads Excel-compatible spreadsheet
     - Print: Opens print dialog

FROM DASHBOARD:
  1. On Admin Dashboard, find Reports section
  2. Click "Generate Report" on any report card
  3. Use export buttons that appear
  4. Or click "View Full Reports Center" for detailed view

AS A DEVELOPER:
  1. Use ReportGenerator utility: generatePDFReport(), generateCSVReport()
  2. Add new report endpoints in server/routes/admin.js
  3. Follow the pattern of existing reports
  4. Call new endpoints from frontend
